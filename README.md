# 🎮 RecomendadorJuegos — Sistema de Recomendación de Videojuegos

Aplicación modular desarrollada en Python para la materia **Estructuras de Datos** (UNAB). Permite gestionar, buscar, ordenar y recomendar videojuegos mediante la implementación progresiva de estructuras de datos y algoritmos.

**Estructura del Proyecto**
* `docs/`: Documentación de requerimientos y entregas.
* `modelos/`: Clases del dominio (`Juego`, `CatalogoJuegos`).
* `ui/`: Interfaz de usuario por consola (`terminal.py`).
* `datos/`: Archivos de prueba (JSON/CSV).
* `main.py`: Punto de entrada principal de la aplicación.

**Instrucciones de Ejecución**
1. Clonar el repositorio.
2. Posicionarse en la carpeta raíz del proyecto.
3. Ejecutar en terminal:
   ```bash
   python main.py
